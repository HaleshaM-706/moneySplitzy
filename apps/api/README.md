# API (NestJS)

Scaffolded as `@money-split/api`.

Quick start:

```bash
pnpm install
pnpm dev:api
```

DB commands (root):

```bash
pnpm db:migrate
pnpm db:seed
pnpm db:studio
```
# API (NestJS)

This folder will contain the NestJS backend application. Implement modules: auth, users, groups, expenses, settlements, notifications.

Run (once implemented):

```bash
cd apps/api
npm install
npm run start:dev
```
